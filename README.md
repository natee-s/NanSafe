# NanSafe

NanSafe คือเว็บแอปแบบ Mobile-first สำหรับช่วยประชาชนจังหวัดน่านติดตามสถานการณ์ภัยพิบัติ เข้าใจความเสี่ยง และรู้ว่าต้องทำอะไรต่อทันที

โค้ดแอปอยู่ใน [`app/`](./app) และเอกสารแนวคิดฉบับเต็มอยู่ที่ [`outputs/NanSafe_End-to-End_Product_Blueprint.md`](./outputs/NanSafe_End-to-End_Product_Blueprint.md)

## เริ่มใช้งาน

```powershell
cd app
npm start
```

จากนั้นเปิด `http://127.0.0.1:4173`

## ขอบเขตปัจจุบัน

- แอปสาธิตทำงานได้แบบ PWA และใช้งานแบบ Mobile-first
- ขอบเขตจังหวัดน่านอ้างอิงข้อมูล GIS ของ DDPM
- สถานการณ์ภัยพิบัติ สถานีวัดน้ำ พื้นที่น้ำท่วม และการแจ้งเตือนเป็นข้อมูลจำลอง
- ก่อนใช้จริง ต้องเชื่อม API ที่ได้รับอนุญาตและใช้กระบวนการประกาศเตือนภัยของหน่วยงานที่รับผิดชอบ
