# NanSafe — Mobile-first Citizen Safety App

NanSafe เป็นเว็บแอปต้นแบบสำหรับประชาชนจังหวัดน่าน ออกแบบจาก `NanSafe_End-to-End_Product_Blueprint.md` เพื่อสาธิตประสบการณ์ “เปิดมาแล้วรู้ทันทีว่าพื้นที่ของฉันปลอดภัยหรือไม่ และต้องทำอะไรต่อ”

## สิ่งที่มีในต้นแบบ

- หน้าหลักที่แสดงสถานะพื้นที่และคำแนะนำที่เปลี่ยนตามระดับภัย
- โหมดสาธิต 5 ระดับ: ปกติ, เฝ้าระวัง, เตรียมพร้อม, อันตราย, อพยพ
- แผนที่ Mobile-first ที่ใช้ขอบเขตจังหวัดน่านจากข้อมูล GIS ของกรมป้องกันและบรรเทาสาธารณภัย (DDPM)
- ชั้นข้อมูลจำลองสำหรับลำน้ำ สถานีวัดน้ำ พื้นที่น้ำท่วม จุดปลอดภัย และเส้นทางอพยพ
- รายละเอียดสถานีวัดน้ำ พร้อมระดับปกติ เกณฑ์เฝ้าระวัง ระดับเสี่ยงน้ำท่วม และค่าในอดีต
- ศูนย์ขอความช่วยเหลือ: เหตุฉุกเฉิน การใช้ตำแหน่ง การโทร และรายงานชุมชน
- หน้าแจ้งเตือน, เช็กลิสต์เตรียมพร้อม และการตั้งค่าการแจ้งเตือนในต้นแบบ
- PWA / Service Worker สำหรับเก็บไฟล์สำคัญไว้ใช้งานเมื่อสัญญาณไม่ดี

## วิธีเปิดใช้งาน

แอปเป็น Static Web App ไม่มีขั้นตอนติดตั้งแพ็กเกจ

จากโฟลเดอร์ที่มีไฟล์ `package.json` ให้เปิดผ่าน Web Server ในเครื่อง เช่น

```powershell
npm start
```

จากนั้นเปิด `http://127.0.0.1:4173` ในเบราว์เซอร์ หรือใช้เครื่องมือ Live Server แล้วเข้าที่ `index.html`

> ไม่แนะนำให้เปิดไฟล์ `index.html` โดยตรง เพราะเบราว์เซอร์จะบล็อกการอ่านขอบเขตแผนที่และ Service Worker ในบางกรณี

## ข้อมูลในต้นแบบ

- **ขอบเขตจังหวัดน่าน:** ข้อมูล FeatureServer ของ DDPM; เก็บแบบย่อไว้ใน `data/nan-boundary.json`
- **ข้อมูลสถานีวัดน้ำ ฝน พื้นที่น้ำท่วม เส้นทาง และ Alert:** ข้อมูลจำลอง เพื่อสาธิต UI และ Flow เท่านั้น
- **เบอร์ฉุกเฉิน:** แสดงเพื่อสาธิตหน้าจอ ต้องยืนยันกับข้อมูลทางการก่อนนำขึ้น Production

## ข้อควรทำก่อน Production

1. เชื่อม Data Adapter กับ API/ระบบสถานีจากหน่วยงานที่ได้รับอนุญาต
2. ให้หน่วยงานผู้มีอำนาจกำหนดเกณฑ์และอนุมัติข้อความแจ้งเตือน
3. ใช้ข้อมูลถนน น้ำท่วม และ Safe Zone ที่ตรวจสอบแล้วกับระบบคำนวณเส้นทาง
4. เพิ่ม Backend ที่รับรายงานประชาชน จัดเก็บอย่างปลอดภัย และมีขั้นตอนตรวจสอบ
5. เชื่อม Web Push, LINE OA และช่องทางเตือนภัยสำรอง
6. ทดสอบการเข้าถึงกับประชาชน ผู้สูงอายุ ผู้พิการ และพื้นที่ที่สัญญาณไม่เสถียร

## โครงสร้างไฟล์

```text
app/
├── index.html                # โครงหน้าแอป
├── app.js                    # สถานการณ์สาธิต การนำทาง และ Interaction
├── styles.css                # Mobile-first UI
├── sw.js                     # Offline cache สำหรับ PWA
├── manifest.webmanifest      # Metadata สำหรับติดตั้ง PWA
└── data/
    └── nan-boundary.json     # ขอบเขตจังหวัดน่าน
```
